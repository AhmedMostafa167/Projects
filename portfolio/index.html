About

I'm Ahmed, an AI engineer. I build LLM systems end to end — retrieval, agents, fine-tuned models and the services around them — and I treat every change as an experiment: define the metric, measure the baseline, change one thing, measure again. No demo-ware.

My route into AI was unusual. I started in quantum computing — as a remote research intern with QUAE (QWorld's UAE chapter) I built an EEG classification pipeline with a Quantum Variational Autoencoder, which became a published paper at the Neurogenomics 2024 conference. That experience taught me how to read papers, run rigorous experiments, and ship reproducible work.

Now I focus on what makes an LLM system dependable in production: evaluation that catches regressions, tracing that shows why an answer went wrong, guardrails tested against hostile input, and the latency and cost of every call. In my latest project a prompt change is only promoted after it beats the current version on the same tests, and every result is written down in an improvement log.

I like working across disciplines — from generative vision and quantum computing to language models. As a Computer Science teaching assistant I designed and led 50 Compiler Theory lab sessions for 600+ students and led tutorials in Linear Algebra, Calculus and Information Retrieval, which sharpened how I explain complex ideas simply.

LLM · AGENTS · LLMOPS

Shopping Assistant

Conversational shopping agent over a 12,730-product catalogue. A LangGraph agent with long-term customer memory runs hybrid search (PostgreSQL full-text + pgvector, fused with RRF, then Cohere rerank) and answers only with products and prices that exist. Retrieval was measured on 127 labelled queries with 95% confidence intervals (top-10 recall: 72% hybrid vs 56% keyword vs 41% vector). Prompts are versioned in Langfuse, behaviour is graded by code checks (12 tasks × 3 runs), memory writes pass a guardrail, the API is monitored with Prometheus and Grafana, and 104 tests run in CI. Every change was measured before and after.

Research Assistant

Agentic RAG over arXiv and the web. I designed a self-correcting LangGraph workflow: query rewriting, hybrid retrieval, relevance grading, cited generation and a reflection step with a bounded retry, using structured outputs for each decision. Dense (Chroma) and keyword (BM25) retrieval are combined with cross-encoder reranking, and a provider factory switches between Groq, Hugging Face, Anthropic and OpenAI with one setting.

Research

PUBLISHED · MACHINE GRAPHICS & VISION 2025

Fine-tuning Stable Diffusion for Generating 2D Floor Plans Using Prompt Templates

We fine-tune Stable Diffusion to generate 2D architectural floor plans from structured prompt templates, training on a curated dataset of floor-plan images spanning diverse design styles and layouts. The work pairs generative modelling with prompt engineering to turn natural-language descriptions into usable architectural drafts.

Machine Graphics & Vision, 34(3), 77–95 Read the paper
PUBLISHED · NEUROGENOMICS 2024

Quantum Denoising in the Realm of Brain-Computer Interfaces: A Preliminary Study

We explore how a Quantum Variational Autoencoder can denoise EEG signals before classification, evaluated on a brain-computer-interface task. Published at the Neurogenomics 2024 Conference; I built the quantum machine-learning pipeline (QVAE denoising followed by LDA classification) and evaluated its generalisation and computational-complexity trade-offs.
